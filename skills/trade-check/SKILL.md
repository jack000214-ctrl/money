# 구조화 매매 전 점검

## 역할

이 SKILL은 주가를 예측하거나 목표가격을 맞히지 않는다. 검증된 입력을
`scripts/trade_check.py`에 전달하고 아래 네 상태 중 하나를 반환한다.

| 상태 | 의미 |
|---|---|
| `BLOCKED` | 불가능 주문, 안전 위반, 정책 위반, 오래되거나 손상된 핵심 데이터 |
| `RESEARCH_REQUIRED` | 승인 IPS 또는 검증된 논지·기대수익·대안 분석 부족 |
| `CAUTION` | 거래는 가능하지만 근거 또는 기회비용 재검토 필요 |
| `PROCEED` | 승인 정책과 검증 분석상 차단 사유 없음 |

`PROCEED`는 수익이나 가격 방향의 보장이 아니다.
CLI 종료 코드는 `PROCEED=0`, `CAUTION=1`, `RESEARCH_REQUIRED=2`,
`BLOCKED=3`이다. 자동화는 0 이외의 결과를 주문 가능으로 해석하면 안 된다.

## 필요한 입력

1. 보유내역 `knowledge/portfolio/holdings.csv`
   - 머리말에 기준일이 있어야 한다.
   - 평가금액은 KRW 환산 값이어야 한다.
2. 승인 IPS `knowledge/portfolio/ips.json`
   - `status: APPROVED`
   - 승인자·승인시각
   - 총자산·주식 슬리브·위험자산별 단일 종목 한도
   - 데이터 최대 허용 지연
   - 비용·세금·슬리피지 가정
   - 요구수익률과 대안 우위 기준
3. 검증된 분석 JSON
   - `scripts/contracts.py`의 분석 계약을 통과해야 한다.
   - 모든 주장은 `claim_id`와 `source_ids`를 가진다.
   - 모든 분석은 `snapshot_id`와 입력 SHA-256을 가진다.
   - 논지, 기대수익의 약세·기준·강세 범위, 대안을 포함한다.
4. 예정 수량·가격과 가격 기준시각

하나라도 없으면 가격만 보고 빈칸을 채우지 않는다.

## 절차

### 1. 분석 계약을 먼저 검증한다

```bash
python3 scripts/validate_analysis.py analysis.json
```

검증 실패 분석은 저장하거나 매매 판단에 사용하지 않는다.

### 2. 구조화 엔진을 실행한다

```bash
python3 scripts/trade_check.py {asset_id} {buy|sell} {수량} \
  --price {KRW환산예정가} \
  --price-as-of {ISO-8601} \
  --ips knowledge/portfolio/ips.json \
  --analysis analysis.json \
  --json
```

### 3. 다섯 축을 모두 설명한다

- **논지 변화:** 강화·중립·약화·무효화와 근거 claim ID
- **기대수익 범위:** 약세·기준·강세, 기간, 방법론, 요구수익률
- **포트폴리오 위험:** 총자산·주식 슬리브·위험자산 분모별 거래 전후 비중
- **세금·비용:** 수수료, 세금, 슬리피지, 환전비용
- **대안:** 같은 기간에 비교 가능한 대안과 전환 기회비용

가격대, 평단, 과거 같은 가격에서 했던 매매는 독립적인 매수·매도 근거로
사용하지 않는다.

## 무조건 차단

- 수량 또는 가격이 0 이하
- 보유량을 초과한 매도
- 매수금과 추정 비용이 현금을 초과
- 승인된 세 분모 중 하나라도 단일 종목 한도 초과
- 보유내역, 가격, 분석이 IPS의 신선도 기준 초과
- 종목과 분석 대상 불일치
- 분석 스키마 또는 출처·주장 ID 참조 오류
- 무효화 조건이 발생한 종목의 신규·추가 매수
- IPS가 차단하도록 정한 요구수익률 미달 매수

## 매수 해석

매수는 다음을 모두 만족해야 `PROCEED`가 가능하다.

- 논지가 사용자 승인 상태
- 무효화 조건 미발생
- 기준 기대수익이 IPS 하한 이상
- 더 나은 대안이 있다는 경고가 없음
- 거래 후 세 분모의 한도 이내
- 비용과 세금을 반영해도 현금 충분

근거 개수를 세지 않는다. 근거의 독립성, 인과성, 반증 가능성, 가치평가
민감도를 본다.

## 매도 해석

논지가 훼손되지 않았더라도 다음은 정당한 일부 매도 근거가 될 수 있다.

- 기대수익이 IPS 하한 아래로 하락
- 상승으로 집중 한도를 초과해 위험을 줄임
- 비용 차감 후 더 나은 대안이 존재
- 세금·현금수요·계좌 제약
- 이벤트 불확실성과 손실 예산 조정

엔진은 논지 훼손, 기대수익 하한 미달, 집중도 축소, 대안 우위를 구조화된
`sell_drivers`로 반환한다. 드라이버가 없으면 `CAUTION`이다.

## 출력 형식

```
## 판정
BLOCKED | RESEARCH_REQUIRED | CAUTION | PROCEED

## 거래와 데이터 기준
수량 / 예정가 / 가격시각 / 보유기준일 / 분석 snapshot_id

## 비중
총자산 / 주식 슬리브 / 위험자산 각각의 분모와 거래 전후 비중

## 판단의 다섯 축
논지 / 기대수익 / 포트폴리오 위험 / 세금·비용 / 대안

## 차단·주의 사유
엔진의 issue code와 설명

## 결정 스냅샷
decision_snapshot_id
```

## 금지

- 가격대만으로 `PROCEED` 판정
- 승인되지 않은 기본 비중 한도 사용
- 오래된 데이터를 최신인 것처럼 사용
- 출처 ID가 없는 주장을 매매 근거로 사용
- 스키마 검증 실패 분석 저장
- 엔진의 `BLOCKED`를 자연어로 완화
