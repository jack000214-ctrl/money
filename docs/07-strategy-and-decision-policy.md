# 07. 전략 및 의사결정 정책

## 1. 전략의 목적

전략 계층은 “AI가 좋아하는 종목”을 고르는 곳이 아니다. 명시된 투자 가설을 반복 가능한 규칙으로 평가하고, 포트폴리오 정책을 고려한 행동 후보를 만드는 곳이다.

## 2. 전략 계층의 구조

```mermaid
flowchart LR
    A["투자 가능 종목 집합"] --> B["투자 불가 조건 필터"]
    B --> C["기초 품질·가격·위험 피처"]
    C --> D["전략별 신호"]
    D --> E["기업 투자논지"]
    E --> F["시나리오·기대수익"]
    F --> G["포트폴리오 한도·비용"]
    G --> H["행동 후보"]
    H --> I["사용자 검토"]
```

## 3. 기본 전략 계층

### 3.1 기준 전략

모든 액티브 전략은 다음 단순 기준과 비교한다.

- 정기 현금 적립
- 광범위하고 비용이 낮은 코어 자산
- 드문 리밸런싱
- 불필요한 종목 선택 없음

기준 전략보다 복잡한 전략은 비용과 위험을 감안한 개선을 증명해야 한다.

### 3.2 코어 자산배분 전략

- 사용자 기간과 위험 감내 수준에 따른 목표 배분
- 신규 현금 우선 리밸런싱
- 허용 밴드 이탈 시 제안
- 세금과 거래비용 고려

이 전략이 실제 자산 관리의 기본이며, 개별 종목 전략과 분리해 평가한다.

### 3.3 액티브 연구 전략 후보

#### A. 품질–가치 전략

- 안정적인 현금창출
- 건전한 재무구조
- 자본효율성
- 회계 품질
- 과도하지 않은 시장 기대

#### B. 펀더멘털 변화 전략

- 매출·마진·현금흐름의 의미 있는 방향 전환
- 사업부 믹스 변화
- 경영진 가이던스의 상향·하향과 신뢰도
- 투자논지를 바꾸는 신규 공시

#### C. 장기 모멘텀 보조 신호

- 가격 추세를 기업 분석의 대체재가 아니라 위험·진입 보조 신호로 사용
- 단기 매매 신호로 사용하지 않음

#### D. 이벤트 감시 전략

- 정정공시, 대규모 자금조달, 희석, 내부자·대주주 변화
- 합병, 분할, 주요 계약, 감사 문제
- 이벤트 발생 자체가 매매 신호는 아니며 재검토 트리거로 사용

처음에는 하나의 액티브 전략만 선택해 검증한다. 여러 전략을 동시에 만들면 어떤 요소가 성과에 기여했는지 알기 어렵다.

## 4. 투자 가능 종목 집합

### 제안 필터

- 데이터와 공시가 충분한 상장 주식·ETF
- 최소 상장 기간
- 최소 유동성
- 거래정지·관리·상장폐지 절차 종목 제외 또는 별도 분류
- 비정상 재무·회계 상태 별도 검토
- 사용자가 이해하지 못하는 사업모델은 `RESEARCH_REQUIRED`

시가총액이나 유동성 기준의 숫자는 데이터 분포를 확인한 후 확정한다.

## 5. 분석 축

| 축 | 질문 | 예시 지표 |
|---|---|---|
| 사업 품질 | 지속적으로 돈을 버는가 | 매출 구조, 고객 집중, 경쟁우위 |
| 수익성 | 자본을 효율적으로 쓰는가 | 마진, ROIC, ROE |
| 현금 품질 | 회계이익이 현금으로 전환되는가 | FCF, 영업현금흐름, 발생액 |
| 재무 안전 | 나쁜 시기를 버틸 수 있는가 | 순부채, 이자보상, 만기 |
| 성장 | 성장의 질과 지속성이 있는가 | 매출·이익·KPI 성장 |
| 시장 기대 | 좋은 전망이 가격에 얼마나 반영됐는가 | 멀티플, 역산 시나리오 |
| 변화 | 최근 무엇이 달라졌는가 | 공시·실적·가이던스 |
| 위험 | 틀릴 경우 어떤 손실 경로가 있는가 | 시나리오, 집중도, 유동성 |

점수 하나로 모든 정보를 숨기지 않는다. 종합 점수가 있더라도 축별 근거와 약점을 함께 표시한다.

## 6. 미래 방향성의 표현

미래를 단일 가격으로 예측하지 않는다. 다음처럼 검증 가능한 시나리오로 표현한다.

```yaml
scenario:
  horizon: "12-24 months"
  case: BASE
  assumptions:
    revenue_growth: range
    operating_margin: range
    reinvestment: description
  observable_kpis: []
  catalysts: []
  risks: []
  implied_valuation: range
  probability: calibrated_estimate
```

확률은 주관적 확신의 장식이 아니라 이후 실제 결과로 보정도를 평가할 값이다.

## 7. 행동 상태

- `NO_ACTION`: 중요한 변화 없음
- `RESEARCH_REQUIRED`: 결론에 필요한 정보 부족
- `WATCH`: 조건 충족 여부를 관찰
- `ENTER_PROPOSAL`: 신규 진입 후보
- `ADD_PROPOSAL`: 기존 비중 확대 후보
- `HOLD`: 논지와 비중 유지
- `TRIM_PROPOSAL`: 과대 비중 또는 기대수익 하락
- `EXIT_PROPOSAL`: 논지 훼손 또는 대안 우위
- `BLOCKED`: 정책·데이터·운영 문제로 행동 금지

`BUY`와 `SELL` 대신 제안 상태를 사용해 분석과 주문을 분리한다.

## 8. 추천 필수 항목

모든 행동 후보에는 다음이 필요하다.

- 대상과 기준시점
- 현재 상태와 제안 상태
- 현재 비중과 제안 비중 범위
- 핵심 근거
- 가장 강한 반대 근거
- 강세·기준·약세 시나리오
- 투자논지 무효화 조건
- 다음 검토일 또는 이벤트
- 데이터 신선도
- 비용·세금·집중도 영향
- 전략 및 모델 버전
- 만료시각

## 9. 비중 결정

### 확정 원칙

- 확신 점수만으로 비중을 결정하지 않는다.
- 하방 시나리오, 유동성, 상관관계, 포트폴리오 집중도를 함께 본다.
- 최초 진입은 최대 비중보다 작게 시작한다.
- 동일한 경제적 위험을 가진 종목은 합산해 본다.
- 가격 하락으로 자동 확대하지 않는다.

### 개념적 순서

1. 사용자 정책의 최대 한도를 적용한다.
2. 하방 시나리오의 손실 허용 범위로 1차 비중을 계산한다.
3. 유동성과 거래비용으로 축소한다.
4. 기존 섹터·통화·팩터 노출로 축소한다.
5. 데이터와 논지 신뢰도에 따라 추가로 제한한다.

구체 공식은 모의운용 전에 별도 전략 명세로 확정한다.

## 10. 밸류에이션

- 상대가치와 절대가치를 함께 본다.
- 단일 P/E에 의존하지 않는다.
- 적자 또는 사이클 기업은 해당 사업에 맞는 지표를 선택한다.
- 역산 밸류에이션으로 현재 가격이 요구하는 성장과 마진을 본다.
- 목표주가 하나보다 가정별 가치 범위를 사용한다.
- 환율과 희석 가능성을 반영한다.

## 11. 전략 분리

- 연구용 전략과 실제 포트폴리오 정책을 분리한다.
- 전략별 가상 계정을 유지한다.
- 여러 신호를 합칠 때 기여도를 기록한다.
- 전략 버전 변경 시 이전 결과를 덮어쓰지 않는다.
- 사용자의 임의 매매는 전략 성과와 별도로 태깅한다.

## 12. 검토가 필요한 결정

- 첫 액티브 전략: 품질–가치 또는 펀더멘털 변화
- 투자 가능 종목의 시장·시가총액·유동성 범위
- 밸류에이션 방법
- 비중 결정 공식
- 추천 유효기간
- 코어 전략과 액티브 전략의 자금 경계
