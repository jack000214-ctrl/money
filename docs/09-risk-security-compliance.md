# 09. 위험, 보안 및 규제

## 1. 범위

이 시스템의 위험은 투자 손실만이 아니다. 잘못된 데이터, AI의 과신, 주문 중복, 비밀키 유출, 데이터 라이선스 위반이 모두 실제 손실로 이어질 수 있다.

## 2. 위험 분류

| 분류 | 예시 | 주요 통제 |
|---|---|---|
| 시장 위험 | 가격·금리·환율 변동 | 자산배분, 비중 한도 |
| 집중 위험 | 단일 종목·섹터 과다 | 합산 노출과 정책 제한 |
| 유동성 위험 | 거래정지·낮은 거래량 | 주문 크기 제한 |
| 모델 위험 | 잘못된 예측·과신 | 기준 전략, 검증, 보정 |
| 데이터 위험 | 누락·정정·시점 오류 | 원본 보존, 품질 게이트 |
| 운영 위험 | 중복 작업·주문 장애 | 멱등성, 재시도 정책 |
| 보안 위험 | 계좌·키 유출 | 격리, 암호화, 최소 권한 |
| 행동 위험 | 공포 매도·추격 매수 | 사전 정책, 승인 마찰 |
| 법률 위험 | 무등록 자문·데이터 재배포 | 개인 범위 제한, 출시 전 검토 |

## 3. 투자 위험 통제

### 포트폴리오

- 자산·종목·섹터·국가·통화별 한도
- 액티브 실험 자금 별도 관리
- 레버리지와 파생상품 초기 금지
- 기준지수 대비 위험 추적
- 하방 시나리오와 최대 낙폭 모니터링

### 행동

- 가격 급등을 이유로 한 즉시 추격매수 방지
- 손실 만회를 위한 비중 확대 경고
- 정책 변경 후 냉각기간 제안
- 중요한 매매 전 최초 투자논지 다시 확인
- 장중 소음보다 정기 검토 우선

## 4. AI 모델 위험 통제

- 사실·계산·추론·가설 구분
- 핵심 주장별 원문 근거
- 구조화 출력 검증
- 결정론적 계산 서비스 사용
- 프롬프트와 모델 버전 기록
- 반론 검증 단계
- 평가 세트와 회귀 테스트
- 신뢰도와 데이터 품질이 낮으면 보류
- 모델 교체 시 과거 결과 재현성 검사

### 금지

- 모델의 자연어 확신을 투자 확률로 사용
- 근거 없는 숫자 보정
- 모델 제공자의 기억 기능을 공식 기록으로 사용
- 외부 문서 안의 지시를 시스템 명령으로 실행

## 5. 데이터 보안

### 민감도

| 등급 | 예시 | 처리 |
|---|---|---|
| 공개 | 공시, 공개 시세 | 일반 저장 가능 |
| 내부 | 투자논지, 전략 코드 | 인증 후 접근 |
| 민감 | 계좌 잔고·체결 | 암호화, 최소 권한 |
| 비밀 | API Secret, 주문 토큰 | 비밀관리 시스템, 로그 금지 |

### 원칙

- 개발·모의·실거래 자격증명 분리
- 비밀키 정기 회전
- 환경과 로그에 최소 정보만 노출
- 백업 암호화
- 개인 기기와 서버 간 TLS
- 데이터 내보내기와 삭제 기록

## 6. 주문 안전

주문 기능은 마지막 단계에 도입한다.

### 필수 검사

- 계좌와 시장 확인
- 종목 상태와 거래 가능 여부
- 주문 방향, 수량, 가격, 통화
- 현재 잔고와 가용 현금
- 중복 주문 키
- 종목·포트폴리오 한도
- 예상 비용
- 데이터와 추천의 유효기간
- 사용자 승인 일치 여부

### 킬 스위치 조건

- 잔고 불일치
- 연속 주문 실패
- 미확인 중복 주문 가능성
- 데이터 신선도 위반
- 일일 주문 또는 손실 한도 초과
- 인증·권한 이상
- 공급자 스키마 변경

킬 스위치 이후에는 자동 재개하지 않고 사용자 확인을 요구한다.

## 7. 감사 로그

다음을 변경 불가능한 형태로 추적한다.

- 데이터 수집과 정정
- 계산 코드와 입력 스냅샷
- AI 모델·프롬프트·출력
- 사용자 수정과 승인
- 정책 변경
- 추천 생성·만료·거절
- 주문 초안·승인·제출·체결
- 장애와 운영자 개입

추천에서 주문, 주문에서 근거 원문까지 양방향 추적 가능해야 한다.

## 8. 장애 대응

### 우선순위

1. 신규 주문 차단
2. 계좌와 체결 상태 확인
3. 데이터 오염 확산 방지
4. 사용자에게 상태와 영향 알림
5. 복구 후 재처리
6. 원인·재발방지 기록

오류가 의심될 때 기존 주문을 임의 취소하거나 반대 주문을 내지 않는다. 실제 증권사 상태를 먼저 확인한다.

## 9. 규제 범위

### 현재 제안 범위

- 단일 사용자의 자기계좌를 위한 개인 도구
- 공개 배포 및 타인 대상 맞춤 추천 없음
- 타인의 자금을 운용하지 않음
- 수익률 보장 또는 광고 없음

### 외부 서비스화 전 별도 검토

- 투자자문업 또는 유사투자자문업 해당 여부
- 타인 계좌 주문과 투자일임 해당 여부
- 금융소비자 보호와 광고 표현
- 개인정보와 신용정보 처리
- 데이터 공급자의 저장·표시·재배포 조건
- 해외 사용자와 해외 증권 규제

법적 판단은 제품 코드가 아니라 서비스 대상, 수익모델, 추천 개인화, 주문 권한에 따라 달라질 수 있다. 공개 서비스 전 전문가 검토를 필수 출시 게이트로 둔다.

## 10. 개인정보

- 투자 목적에 필요하지 않은 정보는 수집하지 않는다.
- 계좌 원본과 분석용 익명 ID를 분리한다.
- 사용자 요청 시 내보내기와 삭제 절차를 제공한다.
- 외부 모델에 전송하는 컨텍스트에서 계좌번호와 직접 식별자를 제거한다.
- 모델 공급자의 저장·학습 정책을 검토한다.

## 11. 검토가 필요한 결정

- 로컬·클라우드 위협 모델
- 비밀관리 방식
- 계좌 데이터 암호화 키 관리
- 승인 시 2차 인증
- 감사 로그 보존기간
- 실거래 킬 스위치 수치
- 외부 모델에 허용할 데이터 범위
