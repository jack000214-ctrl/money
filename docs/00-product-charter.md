# 00. 제품 헌장

## 1. 한 문장 정의

**Personal Investment OS**는 개인의 계좌, 시세, 공시, 재무정보와 투자 원칙을 연결해 “무엇이 변했고, 기존 투자논지가 여전히 유효한가”를 설명하는 개인 전용 투자 의사결정 지원 시스템이다.

## 2. 해결하려는 문제

투자 초보자는 정보의 부족보다 다음 문제를 더 크게 겪는다.

- 공시·뉴스·재무제표의 중요도를 구분하기 어렵다.
- 좋은 회사와 좋은 가격의 주식을 구분하기 어렵다.
- 매수 당시의 이유와 매도 조건을 시간이 지나면 잊는다.
- 감정, 최근 수익률, 소셜 미디어 분위기에 따라 원칙을 바꾸기 쉽다.
- 전략의 성과인지 시장 상승의 결과인지 판단하기 어렵다.
- 백테스트와 실제 운용의 차이를 과소평가하기 쉽다.

이 시스템은 정보를 더 많이 보여주는 대신, **의사결정에 필요한 변화만 선별하고 과거 판단을 검증 가능하게 보존**한다.

## 3. 제품 목표

### 확정

1. 모든 투자 판단을 원문 출처, 데이터 기준시점, 계산 결과에 연결한다.
2. 재무 계산과 포트폴리오 위험 계산은 결정론적 코드로 수행한다.
3. AI는 문서 해석, 변화 설명, 가설 생성, 반론 제시에 사용한다.
4. 추천은 결론뿐 아니라 근거, 반대 근거, 무효화 조건, 유효기간을 포함한다.
5. 아무 변화가 없을 때는 불필요한 매매 신호를 만들지 않는다.
6. 실거래보다 모의운용과 읽기 전용 기능을 먼저 완성한다.

### 장기 목표

- 투자 원칙을 지키도록 돕는 행동적 안전장치
- 보유 종목과 관심 종목의 투자논지 자동 추적
- 기준지수와 비교 가능한 실적 측정
- 사용자의 지식 수준에 맞춘 설명과 학습
- 승인형 주문까지 연결 가능한 안전한 실행 경계

## 4. 비목표

### 금지

- 확정적인 미래 가격 또는 수익률 약속
- 근거 없는 매수·매도 종목의 매일 생성
- LLM이 계산한 숫자를 검증 없이 저장하거나 주문에 사용
- LLM의 증권사 비밀키 접근
- 초기 단계의 레버리지, 신용, 파생상품, 공매도
- 검증되지 않은 전략의 실거래 자동 적용
- 타인에게 개인화된 유료 투자조언을 제공하는 공개 서비스

## 5. 사용자와 사용 상황

### 주 사용자

- AI와 프로그래밍 시스템을 직접 설계·검토할 수 있다.
- 주식, 회계, 포트폴리오 이론은 학습 중이다.
- 시스템의 최종 판단 책임을 직접 진다.
- 분석 근거와 내부 동작을 숨기는 블랙박스를 원하지 않는다.

### 주요 사용 상황

1. 아침 또는 장 마감 후 중요한 변화를 확인한다.
2. 신규 공시가 기존 투자논지에 미치는 영향을 확인한다.
3. 주간 단위로 포트폴리오 집중·환율·섹터 위험을 점검한다.
4. 분기 실적 발표 후 경영진의 과거 약속과 실제 결과를 비교한다.
5. 새로운 종목을 연구하되 기준지수 또는 ETF보다 나은 이유를 명시한다.
6. 매수·보유·축소·청산 제안의 근거와 반증 조건을 검토한다.

## 6. 핵심 제품 원칙

### 6.1 원문 우선

공시, 거래소, 증권사, 중앙은행 등 1차 출처를 우선한다. 뉴스와 커뮤니티는 탐색 신호로는 사용할 수 있지만 사실의 최종 근거로 사용하지 않는다.

### 6.2 시점 보존

현재 알려진 데이터로 과거를 재구성하지 않는다. 그 시점에 실제로 이용 가능했던 데이터와 공시 버전을 보존한다.

### 6.3 계산과 해석의 분리

- 코드: 수익률, 재무비율, 밸류에이션, 위험, 포지션, 세금 추정
- AI: 의미 해석, 요약, 비교, 시나리오, 반론, 추가 확인 질문

### 6.4 설명 가능한 침묵

시스템은 매일 행동을 권하지 않는다. 중요한 변화가 없으면 `NO_ACTION`을 정상 결과로 반환한다.

### 6.5 인간 최종 승인

모든 실거래는 별도의 실행 계층과 사용자 승인을 거친다. 분석 계층은 주문 권한을 갖지 않는다.

## 7. 성공 지표

### 운영 지표

- 데이터 작업 성공률과 지연시간
- 데이터 누락·중복·정정 탐지율
- 출처가 연결된 AI 주장 비율
- 동일 입력 재실행 시 결과 재현 가능성
- 잘못된 경보와 누락된 중요 사건의 비율

### 의사결정 지표

- 투자논지가 사전에 작성된 보유 종목 비율
- 무효화 조건 없이 실행된 매매 비율
- 사용자 정책을 위반한 제안 수
- 추천 확률의 보정도
- 기준지수 대비 성과, 최대 낙폭, 회전율, 비용

### 성공으로 간주하지 않는 지표

- 단기 수익률 하나
- 매수 추천 적중률 하나
- 분석 문서의 길이
- 알림 또는 매매 횟수

## 8. 주요 제약

- 무료 데이터만으로는 정확한 실시간 시세, 컨센서스, 과거 구성종목 데이터가 부족할 수 있다.
- 데이터 재배포 또는 외부 서비스화에는 별도의 라이선스 검토가 필요하다.
- 한국과 미국은 회계·공시·세금·거래시간이 다르므로 시장 어댑터를 분리해야 한다.
- 투자성과에는 보장이 없으며 시스템의 목표는 과정 품질과 위험 통제다.

## 9. 검토가 필요한 결정

- 투자 대상: 한국, 미국, ETF, 개별주 중 1차 범위
- 투자 기간과 월별 추가 투자금
- 현금성 자산을 포함한 전체 자산 중 시스템 관리 범위
- 감내 가능한 최대 낙폭
- 코어 자산과 액티브 실험 자산의 비중
- 세금 계좌와 일반 계좌의 구분
- 로컬 전용 또는 개인 클라우드 배포
- 사용할 증권사와 계좌 연동 방식
