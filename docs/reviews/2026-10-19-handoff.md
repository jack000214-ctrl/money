## 1번을 분석 세션에서 하는 순서

첫 메시지 앞에 `[분석]`을 붙인다. 대상은 삼성전자(005930)처럼 계산 파일이 있는 종목 하나로 시작한다.

```bash
python -m cio refresh 005930 --run --optional   # 시세·공시·재무 갱신 (외부 API 필요)
python -m cio score 005930
python -m cio prepare 005930 --price <현재가> --intent HOLD_REVIEW \
  --held-quantity 80 --average-cost <직접 입력한 평단> \
  --verbatim "<실제 질문>"
# 판단 JSON 작성 후
python -m cio validate DECISION.json
python -m cio record DECISION.json
python -m cio watch run --once                    # 손절가·재질문가가 감시에 들어갔는지 확인
python -m cio watch status
```

`prepare`가 BLOCKED이면 판단을 내지 말고 입력을 채운 뒤 다시 `prepare`한다. 2026-10-19 점검 때 BLOCKED였던 항목은 아래와 같다.

- `calendar`, `events`, `market:KR` 없음
- `^KQ11` 시세 오래됨(97시간), `^VIX`·`KRW=X` 시세 없음
- `filings`, `fundamentals` 낡음
- 보유 원장(`knowledge/portfolio/holdings.csv`) 없음 — 대시보드에서 종목을 저장하면 만들어지는지 먼저 확인할 것

## 주의

- `git add`, `git commit`, `git stash`를 쓰지 않는다. 이번 대화에서 `git stash`를 한 번 실수로 실행했다. `stash@{0}`(10월 15일 항목)과 `.git/packed-refs.lock`(10월 15일 생성, 빈 파일)이 남아 있으니 직접 확인한다. 작업 파일은 온전하다.
- PowerShell에서 한글 출력이 깨진다. 파이썬을 쓸 때는 `PYTHONUTF8=1`을 설정하고, 출력 확인은 `sys.stdout.reconfigure(encoding="utf-8")`를 쓴다.
- heredoc(`<<EOF`)은 PowerShell에서 동작하지 않는다.
- `AGENTS.md`가 가리키는 `MEMORY.md` 경로는 Mac 경로(`/Users/jaehoseo/...`)다. 이 PC에 있는지는 확인하지 않았다.
- `tsc --noEmit` 오류 3건(`cloudflare:workers`, `Fetcher`, `D1Database`)은 `db/index.ts`, `worker/index.ts`의 기존 문제다.
