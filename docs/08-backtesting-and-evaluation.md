# 08. 백테스트 및 평가

## 1. 목적

백테스트는 가장 높은 과거 수익률을 찾는 작업이 아니다. 전략이 알려지지 않은 미래와 실제 거래 제약에서도 살아남을 가능성이 있는지 반증하는 과정이다.

## 2. 검증 순서

```mermaid
flowchart LR
    A["아이디어·경제적 가설"] --> B["고정된 전략 명세"]
    B --> C["과거 데이터 검증"]
    C --> D["워크포워드·미사용 기간"]
    D --> E["모의 포트폴리오"]
    E --> F["소규모 승인형 실거래"]
    F --> G["제한적 확대"]
```

각 단계는 미리 정의된 승격 기준을 통과해야 한다.

## 3. 백테스트 전에 작성할 내용

- 전략이 수익을 낼 것으로 기대하는 경제적 이유
- 투자 가능 종목 집합
- 데이터와 공개시점
- 신호 계산식
- 의사결정 시각
- 주문 시각과 가격 가정
- 비중과 리밸런싱 규칙
- 비용·세금·슬리피지
- 기준지수
- 평가기간
- 성공·실패 기준

테스트 결과를 본 뒤 이 정의를 바꾸면 새 전략 버전으로 취급한다.

## 4. 필수 편향 통제

### 미래정보 사용

의사결정 시점 이후 발표된 재무·공시·지수 구성 정보를 사용할 수 없다.

### 생존편향

현재 상장 종목만 과거에 적용하지 않는다. 상장폐지, 합병, 거래정지 종목을 포함한다.

### 기업행동

배당, 분할, 증자, 권리락, 병합을 올바르게 처리한다.

### 데이터 개정

정정공시와 개정 거시 데이터는 당시 공개 버전을 사용한다.

### 선택편향

많은 전략 중 최고 성과 하나만 보고하지 않는다. 시도한 실험 수와 실패 결과를 기록한다.

### 실행편향

종가를 보고 동일 종가에 거래했다고 가정하지 않는다. 신호 확인 후 실제 가능한 다음 체결 시점을 사용한다.

## 5. 거래 현실성

- 수수료
- 매수·매도 스프레드
- 슬리피지
- 시장 충격
- 세금
- 환전비용
- 배당과 원천징수
- 주문 단위
- 거래정지
- 유동성 한도
- 부분 체결

초기에는 보수적인 비용 가정을 사용하고 민감도 분석을 함께 수행한다.

## 6. 데이터 분할

### 제안

- 전략 개발 구간
- 검증 구간
- 최종 미사용 구간
- 시간 순서를 유지한 워크포워드 평가

시계열을 무작위로 섞어 학습·검증하지 않는다. 시장 국면별 성과도 별도로 본다.

## 7. 비교 기준

최소한 다음과 비교한다.

- 현금 또는 단기 무위험 대안
- 적합한 광범위 시장지수
- 단순 정기 적립·보유
- 단순 동일가중 또는 시가총액가중
- 전략과 유사한 위험 수준의 기준

복잡한 AI 전략은 단순한 규칙 기반 전략보다 나은지 별도로 비교한다.

## 8. 평가 지표

### 수익

- 연환산 수익률
- 누적 수익률
- 기준지수 대비 초과수익
- 월·분기·연도별 일관성

### 위험

- 최대 낙폭
- 변동성
- 하방 변동성
- 손실 기간과 회복 기간
- 최악의 기간별 손실
- 종목·섹터·통화 집중도

### 효율

- 위험조정수익
- 회전율
- 비용 차감 전후 차이
- 자본 사용률
- 거래당 기대값

### 예측 품질

- 확률 보정도
- 시나리오 범위 내 실제 결과 비율
- 중요 사건 분류 정밀도와 재현율
- 논지 무효화 경보의 선행성과 오경보

승률은 참고값일 뿐 핵심 목표가 아니다.

## 9. 스트레스 테스트

- 금융위기 또는 급락 구간
- 금리 급등
- 환율 급변
- 특정 섹터 붕괴
- 거래정지와 유동성 고갈
- 데이터 공급자 장애
- 공시 지연
- 모델 호출 불가
- 비용 2~3배 증가

전략뿐 아니라 시스템의 실패 행동도 검증한다.

## 10. 모의 포트폴리오

백테스트 통과 후 실제 시장 데이터로 미래 방향 모의운용을 한다.

- 신호 생성시각 고정
- 사후 수정 금지
- 실제 가능한 주문과 체결 시뮬레이션
- 배치 지연과 장애 포함
- 사용자의 승인·거절도 기록
- 기준지수와 동일 기간 비교

모의운용 기간은 전략 빈도와 시장 환경을 고려해 정하며, 단기간의 양호한 수익만으로 승격하지 않는다.

## 11. 전략 승격 게이트

### 제안

1. 데이터 품질 검증 통과
2. 경제적 가설이 명확함
3. 미사용 기간에서 기준 대비 합리적 결과
4. 비용·슬리피지 후에도 의미가 남음
5. 특정 종목·기간에 성과가 과도하게 의존하지 않음
6. 스트레스 상황에서 정책 손실 한도를 초과하지 않음
7. 모의운용 결과가 예상 범위와 크게 다르지 않음
8. 재현 가능한 실험 산출물 존재
9. 사용자 승인

정량 임계값은 투자정책 확정 후 설정한다.

## 13. 검토가 필요한 결정

- 전략별 최소 모의운용 기간
- 승격에 필요한 위험·수익 임계값
- 한국 시장의 세금·수수료 모델
- 기준지수
- 과거 구성종목과 상장폐지 데이터 확보 방법
- 실거래 초기 자금 한도
